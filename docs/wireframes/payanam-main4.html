What's reflected in these wireframes

  • Detail page: the “Enquire” button stays fixed at the bottom as you scroll; tapping a gallery photo opens it enlarged (modal).
  • Form: the package is auto-filled but editable; clearing it shows a dropdown list of all packages, so nobody has to type a name from memory.
  • Dashboard: phone number leads each card (the owner’s job is to call back), name sits just under it; every card shows the customer’s message; sent / pending / failed are colour-coded, and a failed enquiry is flagged for manual follow-up. Log out asks for confirmation first.
  • Throughout: secondary text darkened so it’s readable without zooming; emerald used as an accent on white, not a flood.

Still placeholder, pending the owner: exact brand green, real categories, real package content & photos, and the full logo (a simple plane mark stands in for now). About / Contact and Owner login screens are simple and kept as written specs.
